# 달이 케어 🐾

달이의 체중, 식사, 산책, 투약, 컨디션과 건강 메모를 기록하는 개인용 정적 웹입니다.

## 특징
- 서버 없음 / OpenAI API 없음 / 별도 API 비용 없음
- 기록은 브라우저 `localStorage`에 저장
- 체중 추이 그래프
- 소·닭·명태/황태 알러지 메모
- 투약·산책·식사·컨디션 기록
- JSON 백업/복원
- 모바일 대응

## 사용
`index.html`을 브라우저에서 열거나 GitHub Pages로 배포하면 됩니다.

> 기록은 접속한 브라우저에만 저장되므로 다른 기기와 자동 동기화되지는 않습니다. 기기를 바꿀 때는 JSON 백업을 사용하세요.
