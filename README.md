# 달이 케어 🐾

달이의 체중, 식사, 산책, 투약, 컨디션과 건강 메모를 기록하는 개인용 정적 웹입니다.

## 개인정보 보호 방식
- 저장소 코드에는 생일, 알러지, 진료이력, 체중 같은 개인값을 넣지 않습니다.
- 프로필과 일상 기록은 접속한 브라우저의 `localStorage`에만 저장됩니다.
- GitHub나 별도 서버로 기록을 전송하지 않습니다.
- OpenAI API를 사용하지 않아 별도 API 비용이 없습니다.
- 다른 기기와 자동 동기화되지 않으므로 기기 변경 전 JSON 백업을 권장합니다.

## 기능
- 로컬 프로필 설정
- 체중 / 사료 / 산책 / 투약 / 컨디션 기록
- 최근 기록 확인
- 체중 추이 그래프
- 건강 메모
- JSON 백업 / 복원
- 모바일 화면 대응

## 배포
GitHub Pages에서 `main` 브랜치의 `/ (root)`를 배포 소스로 선택하면 됩니다.
